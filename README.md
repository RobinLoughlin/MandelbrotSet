MandelbrotSet

Overview: Simulation of a mandelbrot set

Requirements: 
-Python 3
-NumPy
-Matplotlib
-cmath

How to run:
python MandelbrotSet.py in terminal

Simulation features: 
Creates a simulation of a mandelbrot set with control of the region and resolution

Purpose: I created this program as part of my Computer Simulation course, which was used to delevop my skills in NumPy and simulation
